## Experiments（实验/验证）

### Experiment 1 — 确认被归档的旧笔记文件没有被代码/workflow 引用

**Purpose（目的）**
移动 `logs/` 下 11 个零散笔记文件之前，先确认不会破坏任何东西。

**Command**
```
grep -rln "CHANGELOG\|analysis_notes\|analysis_report\|hn_api_research\|implementation_notes\|integration_proposal\|performance_report_2026\|summary_analysis\|verification_notes\|workflow_changes_guide" --include="*.py" --include="*.yml" --include="*.md" . | grep -v "^./logs/"
```

**Output**
（空 —— 除了 `logs/` 自身之外没有任何匹配）

**Conclusion（结论）**
移动是安全的；真正被代码/workflow 引用的只有 `logs/scrape_run_log.md` 和 `logs/openai_token_usage_log.md`（另外单独用 `grep -n "logs/" news_scraper/*.py .github/workflows/*.yml` 确认过），这两个文件保持原地未动。

### Experiment 2 — 确认 `news_config.yml` 只有一个读取方

**Purpose**
判断把 `news_config.yml` 迁移到 `config/config.yaml` 是否值得冒风险。

**Command**
```
grep -rn "news_config" --include="*.py" --include="*.yml" .
```

**Output**
```
./news_scraper/main.py:920:    cfg = load_config("news_config.yml")
./news_scraper/main.py:921:    print(f"[CONFIG] Loaded news_config.yml")
./_config.yml:61:  - news_config.yml
```

**Conclusion**
只有一处硬编码读取，本身已经被排除在 Jekyll 构建之外，也不包含任何 secret。保留原位置不动 —— 详见 `news_scraper/docs/DECISIONS.md`。
