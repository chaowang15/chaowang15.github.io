# 2026-11-02

## Expandable digest details

- Weekly and monthly digest cards now keep their stored preview image and
  bilingual summaries hidden behind a per-card toggle.
- Digest headlines now open the original article directly instead of detouring
  through the corresponding daily page.
- Details reuse existing daily JSON, so digest generation adds no model or
  article-fetching costs. Missing images produce no placeholder.
- Re-rendered every existing monthly and weekly digest from its saved JSON so
  all historical digest pages use the same expandable layout without changing
  Daily pages or historical digest data.
- Removed the per-card corner button. Digest cards now expand or collapse by
  clicking the compact title/score surface; links and expanded content retain
  their normal behavior.
- Unified Daily, Weekly, and Monthly story cards. All now start expanded and
  use the title/score surface to collapse or reopen details; Daily pages retain
  their existing stories, scores, order, and links.
- Added browser-local story favorites. A star control on each card saves its
  title, summaries, image URL, metadata, and original link to `localStorage`;
  `/hackernews/favorites/` displays the saved list without accounts or a server.
- Added each story's saved creation timestamp to all weekly and monthly cards,
  matching the existing Daily timestamp position and styling.
- Moved the favorite star outside the clickable collapse header so saving a
  story never toggles the card; all pages still share one browser-local list.
- Moved the global Favorites entry into the right side of the main heading row
  on the index and every news page, with a compact star-and-count mobile form.
- Anchored the global Favorites entry to the heading's upper-right corner,
  removed the redundant local-storage subtitle on the Favorites page, and
  grouped each card's favorite and share controls in one bottom-right action row.
- Matched story label badges to the score/comment controls' flex centering so
  their text shares the same visual vertical alignment across card types.
- Moved the favorite/share action group into the card's stats and labels row,
  aligned to its right edge instead of occupying a row below the abstract.
- Added a page-wide Collapse All / Expand All control beside the language
  selector, synchronized with individual card toggles and Favorites rerenders.
- Brought the Favorites page to feature parity with news pages: bilingual and
  page-wide card controls, original tag colors, and live tag counts/filtering
  calculated only from the browser's current Favorites collection.
- Stored and displayed each favorite story's creation date, backfilled dates
  for older favorites from their local source pages, and added Recently Added
  versus Newest Stories sorting with Recently Added kept as the default.
- Linked only the Today's Top Stories heading text to the current daily page
  and removed the redundant View all trending stories link below the list.
